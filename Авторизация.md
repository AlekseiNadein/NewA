Работаем с авторизацией.

При входе рядовой пользователь заполняет поля: компания, ФИО пользователя, пароль. Если у него нет учетной записи - переходит к странице регистрации.

На странице регистрации заполняет поля: компания, ФИО пользователя, e-mail, пароль, повтор пароля.

При регистрации пользователь заносится в общую таблицу пользователей. Булевые поля "авторизован", "администратор", "суперадминитратор" выключены.

По умолчанию в таблице пользователей есть запись суперадминистратора.

Делаем отдельный интерфейс для администраторов системы.  
Отображается список пользователей, можно редактировать их данные и права.  
Для простого администратора отображаются пользователи только его компании.  
Для суперадминистратора отображается вся таблица пользователей.
